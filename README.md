# ТелеШахматы ♞

Шахматы для браузера с необычной фишкой — **телекинезом**. Играется вдвоём на одном
устройстве или против встроенного бота. Никаких сборок, библиотек и интернета для
работы: обычные HTML, CSS и JavaScript.

---

## Что внутри

| Требование | Как сделано |
|---|---|
| Все фигуры ходят по правилам | Свой движок: генерация легальных ходов, проверка безопасности короля |
| Рокировка | Оба вида, с проверкой прав, пустых клеток и атакуемых полей |
| Взятие на проходе | Полноценное, отображается в истории как `exf6 e.p.` |
| Превращение пешки | Окно выбора из четырёх фигур |
| Шах, мат, пат | Плюс ничья по тройному повторению, правилу 50 ходов и недостатку материала |
| Двое на одном устройстве | Режим «Двое на устройстве», курсор и подсветка показывают, чей ход |
| Видно, чей ход | Плашка «Ход: белых/чёрных» + подсветка карточки игрока |
| Кнопка «Новая игра» | В шапке, а также «Ещё партию» в окне конца игры |
| Публичная ссылка | Чистая статика — публикуется на любом хостинге (см. ниже) |

**Бонусы:** игра против бота (три сложности), подсветка доступных ходов, подсветка
последнего хода и шаха, история ходов в нотации SAN с переходом по позициям,
таймер с добавлением времени, мобильная вёрстка, звуки, экспорт PGN, отмена хода,
сворачивание панелей и режим «только доска».

---

## Своя фишка: телекинез

Обычные шахматы плюс одно правило, которого в них нет:

1. **Заряды.** Каждое взятие даёт атакующей стороне **+1 заряд**, максимум три.
2. **Обмен.** Свой ход, потратив **1 заряд**, можно **поменять местами две свои
   фигуры**. Это полноценный ход: после обмена очередь переходит сопернику.

**Чего нельзя:**

* обменять фигуры так, чтобы после обмена ваш король остался под шахом;
* телепортировать пешку на 1-ю или 8-ю линию — превращение бывает только обычным ходом;
* совмещать обмен с рокировкой, взятием на проходе или превращением.

Тактика становится богаче: обмен пешки с ладьёй открывает линию, конь на 7-й линии
становится убийцей, а ферзь с ладьёй мгновенно находят общую цель. Бот умеет
пользоваться телекинезом так же, как и вы.

## Как запустить у себя

**Вариант 1 — вообще ничего не делать.** Откройте файл `index.html` двойным кликом.
Игра запустится в браузере.

**Вариант 2 — локальный сервер** (полезно, если хотите проверить всё с телефона в одной сети):

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

и откройте <http://localhost:8125/>. Остановить — `Ctrl+C` в этом окне.

## Как получить публичную ссылку

Проект состоит из обычных статических файлов, поэтому подойдёт любой хостинг.
Файлы лежат в одной папке — просто загрузите их целиком.

### Способ 1. Netlify Drop (самый быстрый, бесплатно)

1. Откройте <https://app.netlify.com/drop>.
2. Зарегистрируйтесь или войдите (можно через GitHub).
3. Перетащите в поле на странице **всю папку с файлами** (`index.html`,
   `styles.css`, `engine.js`, `bot.js`, `app.js`).
4. Через пару секунд появится ссылка вида `https://<имя-проекта>.netlify.app` —
   готово, сайт уже в интернете. Ссылку можно переименовать в разделе
   **Site settings → Change site name**.

### Способ 2. GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `telechess`).
2. Загрузите в него файлы (кнопка *Add file → Upload files*, перетащите все пять).
3. Откройте **Settings → Pages**, в разделе *Source* выберите веткну `main`,
   папку `/ (root)`, нажмите **Save**.
4. Через минуту-три игра откроется на `https://<логин>.github.io/telechess/`.

### Способ 3. Любой другой хостинг

Netlify, Vercel, Cloudflare Pages, Timeweb, Beget — загрузите папку с файлами
в каталог сайта, всё заработает. Никаких настроек сборки указывать не нужно.

> Если хостинг принимает только один файл, скажите — соберу всё в один файл
> `index.html` со встроенными стилями и скриптами.

## Управление

* **Мышь:** перетащите фигуру или нажмите на неё, затем на клетку назначения.
* **Телефон:** то же самое — тап по фигуре, тап по клетке.
* `Esc` — выйти из режима доски → закрыть журнал или окно → снять выделение.
* `F` — режим «только доска»: шапка и боковые панели скрываются, доска
  разворачивается во весь экран; остаются карточки игроков с часами и зарядами
  и узкая панель из трёх иконок — обмен фигур (⚡ с числом оставшихся зарядов),
  журнал и выход. На компьютере панель стоит вертикально у правого края, на
  телефоне — горизонтальной полосой под доской; на доску она не наезжает.
  Журнал открывается поверх доски и тоже закрывается по `Esc`.
  В этом режиме карточки игроков становятся компактнее (имя, «ваш ход» и заряды
  в одну строку) — освободившееся место отдаётся доске.
* `←` `→` — листать историю ходов (нажатие на доску возвращает к текущей позиции).
* `N` — новая партия.

Каждая боковая панель («Ход», «Ходы», «Настройки») сворачивается и разворачивается
кнопкой-шевроном в её заголовке. В свёрнутом виде остаётся короткая подпись —
например, «Ходы · 24», так что видно, что партия идёт. Состояние панелей и
режима доски запоминается в браузере.

## Оформление

Тёмная тема: чёрный фон, панели-стекло, синие (`#3d7bff`) и красные (`#ff3355`)
акценты с мягким свечением. Цвета самих клеток доски — как были, меняется только
свечение поверх них (последний ход — синее, шах — красное, обмен — красно-синий).

Фигуры — собственный набор из шести SVG, нарисованных вручную в `pieces.js`:
все стоят на общем основании и различаются силуэтом. Белые — светлые с синими
деталями, чёрные — тёмно-синие с красными. Ни шрифтов, ни картинок: набор
одинаково выглядит на любом устройстве.

## Бот

Собственный движок: оценка позиции + поиск PVS с итеративным углублением,
null-move, поздним сокращением ходов, форсированным поиском, таблицей
transposition и killer/history. Оценка учитывает материал, позицию фигур на
доске, подвижность (без учёта связанных фигур), висящие фигуры, безопасность
королей, пешечную структуру, ладьи на открытых линиях и за проходными пешками —
и **выгоду обмена фигурами**, то есть механику телекинеза.

В начале партии бот играет из небольшой дебютной базы (15 популярных начал),
дальше считает сам. Три уровня: «Легко» (неглубоко, иногда ошибается),
«Средне» (~1,3 с на ход) и «Сложно» (~2,3 с на ход, максимум качества).

Насколько он силён, можно проверить самому: `tests-bot-strength.html` решает
10 тактических задач, проверяемых по правилам шахмат (а не сравнением с
«эталонным» ходом движка). После переработки — **10 из 10** против **4 из 10**
у первой версии. Заодно ускорилась сама оценка: 331 → 9 мкс на позицию,
перебор легальных ходов 18,5 → 6,8 мкс.

## Файлы

```
index.html           разметка страницы
styles.css           оформление и адаптивная вёрстка
engine.js            шахматный движок + механика телекинеза (FEN, SAN, рокировка, ep, превращение)
pieces.js            собственный набор фигур (SVG)
bot.js               оценка позиции, поиск и дебютная база
app.js               доска, мышь и тач, история, часы, бот, звук, экспорт PGN
serve.ps1            мини-сервер для локального запуска
tests-*.html         автотесты (для проверки, в игру не входят)
README.md            этот файл
```

Партия автоматически сохраняется в браузере — её можно закрыть и продолжить позже.

## Проверка кода

В папке лежат страницы с автотестами. Откройте их через локальный сервер
(`serve.ps1`) и посмотрите результат на экране:

* `tests-perft.html` — генерация ходов: классические значения perft
  (стартовая позиция до 4 865 609 узлов, Kiwipete и другие контрольные позиции);
* `tests-rules.html` — мат, пат, шах, рокировка, взятие на проходе, превращение,
  ничьи, нотация SAN, обмен фигурами и его запреты, FEN и PGN;
* `tests-bot.html` — бот находит мат в один, берёт на проходе, не отдаёт фигуры,
  все его ходы легальные, партии доходят до конца, замеры скорости поиска;
* `tests-ui.html` — интерфейс целиком: выбор фигуры, ход, перетаскивание,
  рокировка, отмена хода, новая партия, телекинез, превращение, окно мата,
  часы, ответ бота;
* `tests-bot-strength.html` — сила бота: 10 тактических задач (проверяются по
  правилам, а не сравнением с «эталонным» ходом) и матч «Сложно» против «Легко»;
* `tests-pieces.html` — набор фигур в крупном, мелком и на доске.
